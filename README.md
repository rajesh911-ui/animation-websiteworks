# BLOOM — Genesis to Couture

A luxury, cinematic scroll-driven web application revealing the artisanal creation and transformation of a lipstick, from blooming velvet rose petals to high-chroma architectural couture.

## ✨ Key Features
- **427-Frame Canvas Scrubber**: Ultra-smooth canvas sequence scrubbing powered by GSAP ScrollTrigger with instant 100% outward fallback search (never freezes or drops frames).
- **Native Hardware Momentum**: Tuned for two-finger trackpad gestures on laptops/MacBooks and 60Hz/120Hz touch gestures on mobile devices (Android & iPhone).
- **90% Viewport Editorial Framing**: Luxury editorial layout framed at 90vw width and 90vh height with gold borders and backdrop blur.
- **4 Animated Storytelling Chapters**:
  - **01 / GENESIS**: 4-phase botanical blooming sequence.
  - **02 / TRANSFORMATION**: 5-stage molten pigment release and dispersion.
  - **03 / MANUFACTURE**: 5-stage chrome mold shaping and architectural casing.
  - **04 / APPLICATION**: 6-stage couture pickup, single-glide application, and silk velvet finish.
- **Interactive Filmstrip Reels**: Real-time thumbnail previews and segmented HUD progress indicators.

## 🚀 Quick Start
```bash
# Start local Node server
node server.js
```
Visit `http://localhost:3000/` in your web browser.
